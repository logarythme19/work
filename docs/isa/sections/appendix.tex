\section{Reproducibility record}\label{app:repro}
\paragraph{Reference model} \texttt{buck\_fo\_lqi\_fixed\_reference\_v6\_1\_46V\_R2022a.slx},
SHA-256 \texttt{948fbae2679b57ed726a92eeebcae398aaf0ca6b9b3a74216759ca80b390c7fe}.
All plant, mission and logging parameters of Table~\ref{tab:params} were decoded
from its model workspace; the snubber is resistive ($R_s=\SI{100}{k\ohm}$,
$C_s=\infty$) on the MOSFET only, the diode snubber is disabled, and the MOSFET
body diode has $R_d=\SI{0.01}{\ohm}$, $V_{fd}=0$. The saved model initializes
$L$ at \SI{1.2}{A} and $C$ at \SI{12}{V}; all replays of this paper start at the
\SI{24}{V} equilibrium (\SI{2.4}{A}, \SI{24}{V}).

\paragraph{Commands} From the repository root:
{\footnotesize
\begin{verbatim}
python scripts/cmo_formula_first.py   # Sections 3-4, Prop. 2 tests
python scripts/cmo_campaign.py        # 6 families x 6 methods x 30 seeds
python scripts/cmo_analyze.py         # statistics, freeze, switched replay
python scripts/cmo_figures.py; python scripts/cmo_numbers.py
\end{verbatim}}
In MATLAB (R2022a or later, Simscape Electrical, Control System Toolbox):
{\footnotesize
\begin{verbatim}
cmo_formula_first
T = run_cmo_validation(slx, 'results/cmo/controllers.csv');
\end{verbatim}}
The second call replaces only the controller S-function (\texttt{cmo\_sfun},
a line-by-line port of \texttt{cmo/ctrl.py}) and never saves the model.

\paragraph{Seeds and budgets} Seeds $2026091201,\dots,2026091230$; population
12; 240 global and 60 refineBO calls per run; 30 runs per method and family.
Each checkpoint stores the method, seed, best decision vector, objective, the 33
inequalities, the global-stage record and the best-so-far curve.
